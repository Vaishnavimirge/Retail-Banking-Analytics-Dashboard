# 🏦 Retail Banking Analytics Dashboard

An interactive **Power BI dashboard project** created to analyze retail banking data and present key insights across customers, accounts, transactions, loans, and KYC records.

> **Note:** This project uses simulated/dummy banking data for learning and portfolio demonstration purposes. It does not contain real customer or banking information.

---

## 📊 Dashboard Overview

The dashboard contains three analytical pages:

### 1. Executive Overview
Provides a high-level summary of banking performance through key KPIs and visualizations.

**Key metrics include:**
- Total Customers
- Total Accounts
- Repayment %
- Total Balance
- KYC Completion %
- KYC Pending Count
- Accounts by Branch
- Customer Balance
- Loan Status

### 2. Banking Transaction Performance Overview
Analyzes transaction activity and banking cash flow.

**Key metrics include:**
- Transaction Volume
- Transaction Amount
- Total Deposits
- Total Withdrawals
- Transaction Volume by Type
- Transaction Amount by City
- Transaction Volume by Account Type
- Branch-level Deposit and Withdrawal Analysis

### 3. Loan & KYC Analysis
Focuses on loan portfolio performance and KYC status.

**Key metrics include:**
- Total Loan Amount
- Outstanding Loan Amount
- Active Loan Amount
- Closed Loan Amount
- Repayment %
- Loan Amount by Loan Type
- Balance by Branch
- KYC Record Status
- Loan Status Analysis
